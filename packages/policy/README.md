# Policy adapters

The authority service checks current company, agent, source, and tool grants. The controlled tool executor binds each dispatch to its immutable invocation and durable gateway receipt. An uncertain outcome requires provider evidence before the same intent can continue. A retry does not dispatch an uncertain write again.

External metering is an unbound port in this slice. Real turns do not make reservation or settlement calls. Historical usage and audit rows remain available through the authorized export path.

Run `node tests/policy/run.mjs` for the active permission and tool-boundary tests. The runner creates isolated PostgreSQL when `POLICY_TEST_DATABASE_URL` is absent.
